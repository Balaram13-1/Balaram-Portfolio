# Balaram Sethy — Portfolio

Personal portfolio for a junior DevOps / cloud engineer. Built with plain HTML, CSS and JavaScript. No frameworks, no build step.

Live: https://balaram13-1.github.io/

## Features
- Apple-inspired design with light and dark themes (follows system, toggle saved in the browser)
- Sections: About, Skills, Experience, Projects, Credentials, Contact
- Resume download, copy-email button, responsive layout

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Structure
```
index.html                  page markup
style.css                   styles and theme tokens
script.js                   theme toggle, scroll effects, copy email
favicon.svg, og-image.png   icon and link preview image
Balaram_Sethy_Resume.pdf    downloadable resume
```

## Deploy
Push to a repo named `Balaram13-1.github.io`, then enable Settings → Pages → Deploy from `main` / root.
